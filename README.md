# hyprland-rice
This is my current Umbriel rice!

Hope you enjoy.

To install run

```bash
sudo pacman -S --needed noctalia kew superfile imagemagick bluez bluez-utils helix steam sddm starship fish fastfetch kitty curl git gstreamer gst-plugins-good gst-plugins-bad gst-plugins-ugly qt6-svg qt6-virtualkeyboard qt6-declarative qt6-multimedia-ffmpeg

yay -S --needed umbriel-git luciole-git xdg-desktop-portal-umbriel-git bibata-cursor-theme

gsettings set org.gnome.desktop.interface color-scheme 'prefer-dark'
```

then move the files arround

for a jp keyboard (lets note)

```bash
sudo localectl set-x11-keymap jp pc106
```

use the astronaut sddm theme and replace the hyprland kath conf with the one supplied (int the lets note folder) and also add the video (also in the letsnotefolder) to the Backgrounds folder
